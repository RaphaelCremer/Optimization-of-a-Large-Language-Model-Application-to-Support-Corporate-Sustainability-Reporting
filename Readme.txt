Overview

/Training contains files for the construction of the training dataset and the training datasets

/SFT contains files for the superviesed fine-tuning on the training dataset

/Benchmark contains files for the Benchmarking of the base model, reference models and the fine-tuned models as well as the benchmarking results

/Third_Party_Licences contain the plain License text of used third party material
